2. Information Stored Locally by the Game

Sliding Puzzle may store certain game information locally on the player's device so that game progress and game settings can be preserved when the player leaves the Game and returns later.

This information may include:

  • Current game progress.
  • Current puzzle state.
  • Current number of moves.
  • Current game time.
  • Records achieved for different board sizes.
  • Game settings.
  • Selected language, where applicable.
  • Music and sound preferences.
  • Other information necessary to preserve local gameplay progress.

The Game may save this information locally without requiring the player to create an account.

3. Game Progress and Data Loss

Game progress is primarily stored locally on the player's device.

Local data may be lost if the Game is uninstalled, application data is deleted or cleared, the device is reset, the device is damaged, the operating system removes application data, or another technical circumstance affects the device's local storage.

The developer does not guarantee that locally stored progress, records, settings, or other game data can be recovered after such an event.

Important: Uninstalling and reinstalling the Game may result in the loss of locally stored progress or other locally stored game information.

4. Records, Moves and Time

The Game records the number of moves made by the player during a puzzle. The Game also measures the time spent completing a puzzle. The Game may store records for different puzzle sizes according to the information available on the device. Records are gameplay information only and have no monetary value.
