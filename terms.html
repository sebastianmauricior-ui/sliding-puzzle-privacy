2. Description of the Game

Sliding Puzzle is a mobile puzzle game based on rearranging numbered puzzle tiles by sliding them into an available empty space.

The Game provides different puzzle sizes, including:

  • 3×3
  • 4×4
  • 5×5
  • 6×6
  • 7×7

The objective is to arrange the puzzle tiles in the required order.

The Game includes a movement counter, a timer, records for different board sizes, sound effects, music, and other gameplay features.
